# Kalamazoo Church Fires

A standalone web edition of Brian Ream's presentation about the 1925–1926 Kalamazoo church fires.

The project is in source-review and migration-planning stage. See [AGENTS.md](AGENTS.md) for durable project instructions and [docs/SOURCE_REVIEW.md](docs/SOURCE_REVIEW.md) for the current source inventory and narrative analysis.

The intended release is a static, cloneable site with local assets and no runtime dependency on Google Drive, Google Slides, a database, an API, or another external service.
